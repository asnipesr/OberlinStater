Double Click setup.command to finish installing and setting up everything needed to make the stater executable.

This will create an OberlinStater.command file on your Desktop. Double clicking this will run the stater every time.

The first pop up will be the name of the file. After that please read carefully as to not overwrite existing files.


---- HOW TO UPDATE STATTER

ON MAC

- Press "Command + Space". Search and go to Terminal
- Change in OberlinStater directory "cd ~/Desktop/OberlinStater"
- Type "git pull"
